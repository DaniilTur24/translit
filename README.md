# Translit

**English:** a tiny offline hotkey tool that turns Russian typed in Latin letters into Cyrillic, in place. Select `privet kak dela`, press **Control + Option + R** (macOS) or **Ctrl + Alt + R** (Windows), get `привет как дела`. No internet, no AI, no accounts, nothing is logged. macOS: Swift, install with `./install.sh` (see below). Windows: AutoHotkey v2, see [windows/](windows/README.md). MIT licensed. The rest of this README is in Russian.

Маленькая утилита для macOS: выделяете русский текст, набранный латиницей, жмёте **Control + Option + R** — и он заменяется кириллицей на месте.

```
privet kak dela                → привет как дела
ya hochu chtoby eto rabotalo   → я хочу чтобы это работало
mozhesh mne pomoch             → можешь мне помочь
```

Всё локально: без интернета, без AI, без сторонних зависимостей. Один бинарник около 120 КБ, без окон и иконок.

## Установка на новом Mac

Нужна macOS 12 или новее (Intel и Apple Silicon подходят). Эта версия только для macOS. Версия для Windows (AutoHotkey, без системного словаря) лежит в папке [windows/](windows/README.md).

```bash
# 1. Инструменты сборки от Apple (бесплатно, ~1 ГБ). Если `swiftc --version` уже работает, пропустите.
xcode-select --install

# 2. Скачать проект и установить
git clone https://github.com/DaniilTur24/translit.git
cd translit
./test.sh        # необязательно: прогнать тесты конвертера
./install.sh     # собрать, поставить в ~/Applications, включить автозапуск
```

Затем один раз вручную: **Системные настройки → Конфиденциальность и безопасность → Универсальный доступ (Accessibility)** → включить **Translit**. Без этого macOS не разрешит программе нажимать Cmd+C / Cmd+V. До выдачи разрешения хоткей просто пищит.

## Использование

1. Напишите текст латиницей в любом поле.
2. Выделите его.
3. Нажмите **Control + Option + R**.

Выделенный текст заменится, курсор останется после него, можно писать дальше. Если ничего не выделено, ничего не происходит. Если в выделении нет латиницы, текст не меняется.

Хоткей меняется в начале [Sources/main.swift](Sources/main.swift), после чего нужен `./install.sh`.

## Что умеет конвертер

- `ya yu yo ye` → я ю ё е; `zh sh shch ch kh h ts` → ж ш щ ч х х ц; `j` → й; `x` → кс; `w` → в; `c` → ц перед e/i/y, иначе к.
- `y` после гласной — это «й» (`seychas` → сейчас, `moy` → мой), после согласной — «ы» (`chtoby` → чтобы). Окончания `iy`, `yy`, `yj` дают ий, ый, ый.
- Мягкий и твёрдый знак: `'` → ь, `''` или `"` → ъ. Твёрдый знак после приставок ставится сам: `ob'yekt` и `obyekt` → объект, `pod'ezd` → подъезд. `semye` → семье.
- `tsya` на конце слова → «тся», а после «хочу / надо / чтобы / можно…» → «ться»: `kazhetsya` → кажется, `hochu uchitsya` → хочу учиться.
- `ts` перед согласной читается как «тс»: `otsutstvie` → отсутствие, `bogatstvo` → богатство. Но `nemetskiy` → немецкий.
- Регистр сохраняется: `Privet`, `PRIVET`, `Shchuka` → Привет, ПРИВЕТ, Щука.
- Не трогаются: URL, e-mail, пути, `mp3`, `iPhone`, `ChatGPT`, кириллица, цифры, знаки препинания, пробелы и переводы строк.

### Автоисправление очевидного

Правила и небольшой словарь в [Sources/Fixes.swift](Sources/Fixes.swift), без AI: потерянный мягкий знак (`pomoch` → помочь, `est` → есть, `mozhesh` → можешь, `delat` → делать, `dvadtsat` → двадцать, `vozmozhnost` → возможность), `eto` → это, названия месяцев, числительные, несколько имён. Правила подобраны так, чтобы не менять смысл, но у словаря есть цена: `ест` всегда станет «есть». Если мешает, добавьте исключение или поставьте `smartFixes: false` в вызове `Translit.convert`.

### Страховка: словарь macOS

После правил программа спрашивает встроенный русский словарь macOS (тот же, что подчёркивает опечатки в Notes) и использует его двумя способами:

1. Если слово словарю неизвестно, пробуются мелкие правки: мягкий знак в конце или внутри, `э` вместо `е`, `ий` ↔ `ый`, конечное `и` → `й`. Берётся первый вариант, который словарь знает: `sovetovat` → советовать, `zdes` → здесь, `dozhd` → дождь, `bolnitsa` → больница, `dnei` → дней, `dorogoi` → дорогой.
2. Словарь снисходителен и принимает часть опечаток за слова (`очен`, `пят`). Тогда помогает его автодополнение, которое ставит частые слова первыми: если первое дополнение равно слову с `ь`, а самого слова среди дополнений нет, добавляется `ь` (`очен` → очень, `ploshchad` → площадь). Настоящие слова `ответ` и `вес` перечисляют сами себя, поэтому остаются.

Слово, которому ничего не подходит (имя, сленг), не меняется. Словарь встроен в систему: ничего не скачивается, хоткей остался один. Если русского словаря в системе нет, работают только правила.

## Безопасность

- Пароли: если включён secure input (в любом приложении фокус в поле пароля) или у активного элемента роль `AXSecureTextField`, программа ничего не копирует, а только пищит.
- Ничего не логируется, не сохраняется и не отправляется. В `~/Library/Logs/Translit.log` попадают только ошибки запуска.
- Буфер обмена: перед заменой делается полная копия (все элементы и все типы: текст, картинки, файлы) и после вставки возвращается. Временный текст помечен `org.nspasteboard.TransientType`, поэтому менеджеры буфера его игнорируют. Но сам Cmd+C выделенного фрагмента менеджер буфера увидеть может.
- Пока хоткей не нажат, программа не читает клавиатуру и не вмешивается в набор.

## Запуск, остановка, удаление

```bash
launchctl bootout gui/$(id -u)/local.translit                                      # остановить до следующего входа
launchctl bootstrap gui/$(id -u) ~/Library/LaunchAgents/local.translit.plist       # запустить снова
./uninstall.sh                                                                     # удалить полностью
```

`uninstall.sh` останавливает программу и удаляет приложение, LaunchAgent, лог и запись в Accessibility. Папка проекта остаётся.

## Если не работает

- **Пищит и ничего не заменяет.** Либо нет разрешения Accessibility, либо фокус в поле пароля или включён secure input (например, «Secure Keyboard Entry» в терминале).
- **После пересборки перестало работать.** Приложение подписано ad-hoc, и macOS привязывает разрешение к подписи. В Accessibility удалите Translit (−), снова запустите `./install.sh` и включите заново.
- **Хоткей не срабатывает.** Другое приложение заняло Control+Option+R. Сообщение об этом будет в `~/Library/Logs/Translit.log`. Выберите другую комбинацию.
- **Вставилось старое содержимое буфера.** Приложение обрабатывает вставку дольше 300 мс. Увеличьте `pasteSettleTime` в [Sources/SelectionReplacer.swift](Sources/SelectionReplacer.swift).

## Устройство и будущий режим «после пробела»

| Файл | Роль |
|---|---|
| `Sources/Translit.swift` | чистое преобразование строки, без AppKit и состояния |
| `Sources/Fixes.swift` | необязательные правила, словарь исправлений и починка по словарю (`repair`) |
| `Sources/SelectionReplacer.swift` | «заменить выделенное на `f(выделенное)`» через буфер обмена |
| `Sources/main.swift` | хоткей, запуск и подключение словаря macOS |

Режим «privet␣ → привет␣» понадобится добавить отдельным файлом: `CGEventTap` на пробел, который выделяет предыдущее слово (Option+Shift+←) и вызывает уже готовый `SelectionReplacer.run { Translit.convert($0) }`. Конвертер и замена менять не придётся.
