# Translit для Windows

То же, что на Mac: выделяете русский текст, набранный латиницей, жмёте **Ctrl + Alt + R**, и он заменяется кириллицей на месте. Без интернета и без AI. Версия на [AutoHotkey v2](https://www.autohotkey.com/), правила конвертера те же, что в [Sources/Translit.swift](../Sources/Translit.swift).

**Статус: первая версия, написана без возможности запустить её на Windows.** Сначала запустите тесты (шаг 2), они покажут, что работает.

## Установка

1. Поставьте AutoHotkey **v2** (не v1): `winget install AutoHotkey.AutoHotkey` или установщик с autohotkey.com. Права администратора не нужны, если выбрать установку для текущего пользователя.
2. Скачайте проект и дважды щёлкните **`windows/Tests.ahk`**. Должно появиться окно «OK: 96 checks passed». Если пишет FAILED или ошибку скрипта, пришлите текст окна.
3. Дважды щёлкните **`windows/Translit.ahk`**. В трее (у часов, возможно под стрелкой ^) появится значок AutoHotkey. Это и есть программа.
4. Правый клик по значку → **Запускать при входе в Windows**, чтобы она стартовала сама.

## Использование

Написать текст латиницей → выделить → **Ctrl + Alt + R**. Если ничего не выделено, ничего не происходит. Хоткей привязан к физической клавише R, поэтому работает и при русской раскладке. Сменить его можно в начале [Translit.ahk](Translit.ahk).

Остановить: правый клик по значку в трее → **Выход**. Удалить: выйти и убрать галочку автозапуска, затем удалить папку.

## Чем отличается от версии для Mac

- **Нет словаря.** Нет автоисправления через системный словарь (`sovetovat` → советовать): остаются правила и встроенный список слов из [Fixes.ahk](Fixes.ahk) (`pomoch` → помочь, `eto` → это, `ochen` → очень и т. д.).
- **Пароли.** Поле пароля распознаётся только в обычных окнах Windows (классический `Edit`). В браузерах и в приложениях на Electron поле пароля не определяется: не нажимайте хоткей там, где выделен пароль.
- **Буфер обмена.** Содержимое буфера сохраняется со всеми форматами и возвращается через 0,3 с. Но история буфера Windows (Win+V) может запомнить временно скопированный фрагмент.
- **Окна с правами администратора.** Обычная программа не может отправлять Ctrl+C/Ctrl+V в окна, запущенные от администратора. Для них запустите `Translit.ahk` тоже от администратора.

## Файлы

| Файл | Роль |
|---|---|
| `Converter.ahk` | чистое преобразование строки (порт `Translit.swift`) |
| `Fixes.ahk` | правила и словарь исправлений (порт `Fixes.swift` без части про системный словарь) |
| `Replacer.ahk` | «заменить выделенное» через буфер обмена, проверка поля пароля |
| `Translit.ahk` | хоткей, значок в трее, автозапуск |
| `Tests.ahk` | 96 проверок конвертера, сгенерированы из [Tests/main.swift](../Tests/main.swift) |
