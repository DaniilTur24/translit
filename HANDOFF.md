# Translit: сводка для продолжения на другом ноутбуке

Репозиторий: https://github.com/DaniilTur24/translit (публичный, ветка `main`).

## Что это и зачем

Утилита для macOS: выделяете русский текст, набранный латиницей (`privet kak dela`), жмёте **Control + Option + R**, и он заменяется кириллицей на месте. Без интернета, без AI, без подписок. Нужна пользователю с немецкой клавиатурой QWERTZ, который не хочет менять раскладку.

## Состояние

- Готово и работает на рабочем Mac (macOS 15.7.9, Intel): конвертер, автоисправление, хоткей, замена через буфер обмена, автозапуск через LaunchAgent. Живую замену пользователь проверил в Notes. Браузер, ChatGPT и Telegram не проверялись.
- 95 тестов конвертера проходят (`./test.sh`).
- Осталось сделать на домашнем ноутбуке: установить и выдать разрешение Accessibility. Какая там система и сколько RAM, неизвестно.

## Установка на новом Mac (macOS 12+)

```bash
xcode-select --install            # если `swiftc --version` не работает
git clone https://github.com/DaniilTur24/translit.git
cd translit
./test.sh                         # необязательно
./install.sh
```

Затем вручную: Системные настройки → Конфиденциальность и безопасность → Универсальный доступ → включить **Translit**. Разрешение выдаётся заново на каждом компьютере. После пересборки (`./install.sh`) его может потребоваться включить заново: приложение подписано ad-hoc.

Остановить: `launchctl bootout gui/$(id -u)/local.translit`. Удалить полностью: `./uninstall.sh`.

## Устройство

| Файл | Роль |
|---|---|
| `Sources/Translit.swift` | чистая функция `Translit.convert(_:smartFixes:)`, без AppKit и состояния |
| `Sources/Fixes.swift` | необязательные правила и словарь (потерянные ь/ъ, э, числительные, месяцы, имена) |
| `Sources/SelectionReplacer.swift` | выделенное → Cmd+C → преобразование → Cmd+V → восстановление буфера; отказ в полях пароля |
| `Sources/main.swift` | хоткей через Carbon `RegisterEventHotKey`, константы хоткея в начале файла |
| `Tests/main.swift` | 95 проверок, запуск `./test.sh` |
| `install.sh` / `uninstall.sh` | сборка `swiftc`, копия в `~/Applications/Translit.app`, LaunchAgent `local.translit` |

## Принятые решения

- **Swift, а не Hammerspoon:** нет сторонних зависимостей, конвертер тестируется сразу, один бинарник около 120 КБ и около 12 МБ памяти.
- **Буфер обмена:** снимок всех элементов и типов перед заменой, восстановление через 300 мс (`pasteSettleTime`). Временный текст помечен `org.nspasteboard.TransientType`.
- **Ничего не логируется и не сохраняется.** Лог только для ошибок запуска.
- **Решения конвертера:** `sch` → «сч» (не «щ»), `shch` → «щ», `x` → «кс», `w` → «в», `ts` перед согласной → «тс» (кроме `tsk`), `tsya` на конце → «тся» или «ться» после слов вроде «хочу / надо / чтобы», `'` → ь, `''` или `"` → ъ, твёрдый знак после приставок ob/pod/ot/iz/raz.
- **Известная цена словаря:** `ест` всегда превращается в «есть».
- Хоткей не зависит от раскладки (физические коды клавиш). Для Dvorak и Colemak отправка Cmd+C/V может не сработать.

## Идеи на потом (по убыванию ценности)

1. **Словарь частотности вместо ручных правил:** перебор вариантов написания (`ест` / `есть`, `учится` / `учиться`) и выбор слова из словаря на 50–100 тысяч слов (OpenCorpora, частотные списки Викисловаря). Размер 2–5 МБ, офлайн. Источник и лицензию проверить перед скачиванием.
2. **Повторное нажатие хоткея перебирает варианты** (`ест` → `есть` → `ест`).
3. **Режим «после пробела»**: `CGEventTap` на пробел, замена без буфера. Нужны разрешение Input Monitoring, выключатель, исключения для приложений и отмена Backspace сразу после замены.
4. Таблица частых пар слов для выбора между «учится» и «учиться». Личный словарь `~/.translit/words.txt`, вручную.
5. **ИИ-правка** (опечатки, пунктуация) по отдельному хоткею через локальную модель (Ollama). Нужно согласие на установку Ollama и скачивание модели. Qwen2.5 3B: около 3 ГБ RAM, на Intel без GPU 5–15 секунд на сообщение, на Apple Silicon 1–3 секунды. На 8 ГБ только 1.5–3B, на 16 ГБ можно 7B. Встроенные модели Apple недоступны на Intel и macOS 15.
6. **Версия для Windows:** AutoHotkey v2, конвертер портируется один в один (около 250 строк логики), те же 95 тестов. Защита паролей через UI Automation сложнее. Ollama работает и на Windows.
7. Подсказки продолжения слова с окошком у курсора: сложно, определение позиции курсора ненадёжно в браузерах и Electron.

## Ограничения, о которых стоит помнить

- Все слова латиницей в выделении конвертируются, включая английские. Защищены только URL, e-mail, пути, `mp3`-подобные коды и camelCase (`iPhone`, `ChatGPT`).
- В редакторах вроде VS Code Cmd+C без выделения копирует строку целиком, и хоткей может превратить её в текст.
- Менеджеры буфера обмена могут записать сам скопированный фрагмент (Cmd+C), хотя не видят подставленный результат.
